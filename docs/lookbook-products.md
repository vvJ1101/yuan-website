# Lookbook 造型与搭配单品

前端已支持关联展示；RANYEPERSONAL 中间造型目前绑定三张用户批准的 AI 白底示意图，公开标注 AI 示意，后续替换真实摄影。其他未绑定造型不展示空侧栏。这里不是后台上传功能的完成声明。

## 数据约定

- 每个活动品牌的 `products` 是可复用产品库：`id`、白底图 `image`、中英文 `name`、`category` 必填；`styleNumber`、中英文 `description`、`material`、`color` 可选，缺失时不展示。
- 分类：`top` 上装、`bottom` 下装、`dress` 连衣裙、`outerwear` 外套、`shoes` 鞋履、`bag` 包袋、`accessory` 配饰。
- 每个 `LookbookItem` 保留模特图 `image`，可添加 `productIds`；显示顺序遵循这个数组。同一个产品 ID 可用于多张造型图，不重复上传。
- 未关联、关联失效或无产品图片时，自动回退到纯大图；不存在的产品不渲染。重复 ID 只出现一次。
- 产品 ID 在品牌库内唯一，上传后台接入时应校验唯一性、图片路径、分类、中英文名称和品牌归属；不得自动猜测模特身上的单品。

## 阅读交互

桌面左侧完整大图、右侧单品，三件单品在常见桌面高度下优先一屏显示。选择单品后主图区显示产品大图，固定的小模特图提供对照和返回完整造型入口，不随商品列表滚走。切换造型或重新打开时清空单品选择。Esc 在产品视图先返回造型，再按一次关闭；关闭按钮直接关闭。键盘左右键切换造型。

点击大图或放大按钮切换 1 倍 / 2 倍；双指可在 1–3 倍之间缩放，放大后拖动查看细节。正常比例时水平滑动切换造型；放大拖动、双指手势和竖向滚动不会切换。模特/产品切换后恢复全图。大图区单指竖向拖动带动移动端内容滚动；单品区保持原生上下滚动。

900px 及以下采用上图下单品，内容区滚动，顶部关闭和底部造型切换保持可用。图片保持原比例，产品栏缺省隐藏。

## 后台阶段

需要产品上传/编辑、产品库检索、多选绑定、造型内单品排序、双语编辑及保存发布接口。现阶段数据由 `EventBrand.products` 与 `LookbookItem.productIds` 提供，不包含这些后台能力。
