# YUAN SHOWROOM 官网视觉还原设计

## 项目目标

依据 `/Users/vv/Documents/YUAN开发/新官网素材/` 中的十张页面效果图，重构当前 YUAN SHOWROOM 官网。第一阶段只完成公开官网，优先保证桌面端视觉还原、页面关系和双语浏览完整；后台管理、数据库、登录与线上内容编辑留到后续阶段。

效果图是视觉布局、比例、间距和留白的基准。本设计文档中已确认的信息架构和内容调整优先于效果图中的旧导航顺序与旧品牌分类。

## 已确认决策

- 第一阶段只建设官网，不建设后台。
- 后台未来借鉴内部学院的管理界面、登录与权限体系，但使用独立数据库和独立部署。
- 第一阶段使用本地结构化数据，页面组件不直接写死业务内容，为后续 API 数据源预留边界。
- 官网提供完整中文和英文版本；英文文案由本项目完成专业翻译。
- 使用 `/cn` 和 `/en` 独立语言路由，切换语言时保留当前页面和品牌。
- 桌面端按效果图还原；移动端在不改变视觉语言和内容顺序的前提下响应式适配。
- 允许从效果图中裁切临时图片，后续以正式原图或后台素材替换。
- NOW 保留品牌 Lookbook、楼层导览和预约通道三个入口。
- 品牌分类使用 `RTW`、`FTW` 和 `ACC`。

## 信息架构

### 全局导航

所有公开页面使用同一个固定 Header，顺序为：

1. BRANDS
2. ABOUT
3. NOW
4. ON-SITE
5. RECAP

左侧为两行 `YUAN / SHOWROOM` 标识，点击后返回当前语言首页。右侧为 `CN / EN`。Header 不出现汉堡菜单、额外按钮或页面间不同的间距。

## 页面设计

### 封面

纯白首屏，只显示统一 Header 和超大两行 `YUAN / SHOWROOM`。不添加图片、正文、说明或装饰。桌面目标尺寸内完整显示且不产生滚动条。

### BRANDS

页面左侧显示 `BRANDS`、合作品牌说明、三类品牌名称列表；右侧为统一尺寸的品牌图片矩阵。品牌名称叠加在图片底部。卡片可点击进入 Brand Room。

分类对用户显示为：成衣 `RTW`、鞋履 `FTW`、配饰 `ACC`。英文版只显示英文分类名称和缩写。

### Brand Room

品牌详情使用全屏左右分栏。左侧显示品牌名称、城市、`BRAND ROOM` 和品牌介绍；右侧由一张主视觉与两张辅助图片组成。图片和文字顶部对齐，四周保留效果图对应留白。

页面右上角使用 `CLOSE` 返回品牌列表，底部左右箭头切换前后品牌。不增加镜头按钮、灯箱或额外 UI。

### ABOUT

左侧显示 `ABOUT`、短横、定位介绍和 `READ MORE`；右侧显示横向大图。底部显示 `50+`、`3000+`、`4` 三组数据背书。整体按效果图形成一个完整首屏，图片与左侧文字顶部严格对齐。

### NOW

NOW 首页显示当季订货会主题、季节、日期和主题图片。右侧仅使用文字入口：

- 参展品牌 / LOOKBOOK
- 楼层介绍 / 导览图
- 预约通道 / 预约二维码

入口不增加箭头、横线或附加图片。

### LOOKBOOK

页面第一部分为当季参展品牌矩阵，支持纵向滚动查看更多品牌。点击品牌后在同一页面进入或定位到品牌 Lookbook 详情。详情包含品牌介绍、基础资料、一张主图与多张辅助图片，布局按效果图比例实现。

### FLOOR MAP

全屏长页面以楼层导览图为主要视觉，显示楼层、房间编号与品牌现场位置。不增加导览图之外的说明模块。允许纵向滚动。

### APPOINTMENT

白底居中显示预约二维码，不增加说明模块。保留效果图中的必要标题、活动名称与日期信息，中英文分别展示。

### ON-SITE

左侧显示现场服务名称、介绍、位置、供应内容与服务时段；右侧为独立的 16:9 图片轮播。第一阶段内容覆盖咖啡、甜品和轻食等时装周现场服务。轮播保持克制，只提供必要的左右切换与当前页状态。

### RECAP

页面显示 `RECAP` 与“往季订货会回顾”，下方按效果图的纵向内容节奏排列往季海报。每项包含海报、季节名称与主题名称。页面允许纵向滚动。

## 双语规则

- `/cn` 与 `/en` 使用同一套组件、内容关系、品牌排序和素材。
- 每条可翻译内容同时保存 `cn` 与 `en`，避免两套独立数据产生关联错位。
- 品牌名、设计师姓名、季节编号、网址和官方专有名称保持原文。
- 英文使用时装行业和品牌运营语境，不做机械逐字翻译。
- `CN / EN` 在深层页面切换时保留当前 slug；如果对应语言内容缺失，则仍显示相同品牌的另一语言基础信息，不跳回首页。

## 素材策略

- 效果图位于 `/Users/vv/Documents/YUAN开发/新官网素材/`，仅作为还原基准和临时裁切来源。
- 临时网页素材统一进入 `public/images/showroom`，使用可维护的英文文件名。
- 每张裁切图保留来源页面记录，方便后续逐张替换。
- 图片使用固定比例容器与明确的裁切规则，后续替换不同尺寸原图时不破坏布局。
- 不修改素材目录中的原始效果图。

## 视觉系统

- 背景：`#FFFFFF`。
- 主要文字：黑色。
- 字体：Helvetica/Arial 系无衬线字体；中文使用系统中文无衬线回退。
- 风格：极简、克制、大留白，不增加装饰性卡片、渐变或复杂动效。
- Header 的高度、页边距、导航位置和字号由全局变量统一控制。
- 桌面布局按效果图原始尺寸等比例换算，不把截图本身作为整页背景。
- 动效仅用于必要的轮播切换、链接状态和轻微图片反馈，并遵守 `prefers-reduced-motion`。

## 响应式策略

- 1366×768、1440×900、1920×1080 为桌面验收尺寸。
- 首页、ABOUT、BRANDS、NOW 和 ON-SITE 等展示型页面在桌面目标尺寸内完整呈现，不产生横向或纵向滚动条。
- LOOKBOOK、FLOOR MAP 和 RECAP 为长内容页，只允许纵向滚动。
- 平板减少列数和空白跨度，保持内容层级。
- 手机端按桌面阅读顺序收敛为单列或局部双列，不依赖悬停，不产生横向溢出。
- Header 在移动端仍保留完整导航，不改成汉堡菜单；通过紧凑字号与可控换行适配。

## 后台演进边界

第一阶段不包含数据库、后台、登录、线上内容编辑或对象存储。未来后台：

- 使用独立数据库和独立部署，不与内部学院共享业务数据或账号库。
- 可借鉴内部学院的认证、角色权限、上传和审计实现。
- 后台只管理正文、双语内容、品牌资料、图片、顺序、发布状态和 SEO。
- Header 坐标、字体、网格、留白和图片比例规则不开放自由编辑，避免破坏视觉还原。
- 后台应支持草稿/发布、图片顺序调整、尺寸校验与页面预览。

## 验收标准

- 全站导航顺序为 `BRANDS / ABOUT / NOW / ON-SITE / RECAP`。
- 所有页面共用完全一致的 Header。
- 品牌正确归入 `RTW`、`FTW`、`ACC`，其中 LUCIA TACCI 与 PIÉTON ÉPISODE 属于 FTW，HELEN KAMINSKI 与 REINDEER 属于 ACC。
- Brand Room、NOW 三个入口、Lookbook 品牌入口和品牌前后切换均可操作。
- 中文和英文覆盖全部公开页面，语言切换保持当前路径。
- 桌面目标尺寸内无意外滚动条、内容裁切、文字遮挡或图片越界。
- 长内容页无横向滚动。
- 移动端无横向溢出，所有交互可触控和键盘操作。
- 页面逐一与效果图并排对照，重点检查页边距、基线、图片比例与首屏完整度。
- 测试、ESLint、TypeScript 类型检查与生产构建全部通过。

## 第一阶段不包含

- 管理后台与登录页面。
- 数据库与内容 API。
- 对象存储或第三方 CMS。
- 自由拖拽式页面编辑。
- 对效果图之外的视觉重新设计。
