# YUAN SHOWROOM 编辑式品牌体验升级设计

## 目标

将当前规则、平均、偏传统企业官网的单页展示升级为更具时尚编辑感的品牌浏览体验。首页通过非对称图片节奏建立品牌调性，合作品牌从静态名单升级为可点击的视觉入口，并为每个品牌提供可独立访问和分享的详情页面。

本次仍是静态前台升级，不接入后台、百度网盘接口或在线内容编辑。

## 已确认决策

- 完整删除 About 下方的黑色数据墙，不用其他数据卡片替代。
- 采用已确认的 A 方向「编辑式拼贴」：暖白底、非对称留白、大小图片错位、克制动效。
- 所有合作品牌均可点击并进入 `/brands/[slug]` 独立详情页。
- PLAYAPLY 使用本次提供的真实素材；其他品牌先使用明确的占位视觉和现有简介，后续逐一替换。
- Aano Café 素材属于展厅/订货会体验内容，不作为合作品牌或商品内容。
- 保留当前业务信息范围，不在本轮重写公司定位或扩展后台能力。

## 首页改造

### About

保留现有图文介绍，删除 `byTheNumbers` 黑色数据区及其数据源。About 图文结束后直接进入下一业务模块，并调整底部留白，使页面衔接自然。

### 品牌服务

现有 3 × 2 等宽卡片改为编辑式跨栏布局。图片使用大幅横图、竖图和较小细节图交错组合，文字与图片不再全部同基线排列。内容顺序和业务文案保持不变，移动端收敛为清晰单列。

### 合作品牌

移除当前 Logo 行与五列文字表格的组合，改为可点击的不等高品牌图片拼贴：

- 每张卡片显示品牌预览图、品牌名、国家和品类。
- 图片比例按预设节奏轮换，不由内容随机决定，保证整体构图可控。
- 桌面端悬停时图片轻微放大、图注上移并出现「查看品牌」。
- 键盘聚焦提供等价视觉反馈；触屏端始终显示清晰图注，不依赖悬停。
- 点击卡片进入对应 `/brands/[slug]` 页面。
- 品牌区仍保留合作买手与买手店名单，但降低其视觉权重，作为品牌矩阵后的渠道背书。

### 展厅与订货会

利用本次提供的前台、PLAYAPLY 装置、挂装陈列和 Aano Café 空间素材，加强横竖图混排与空间细节叙事。Aano Café 作为订货会体验的一部分出现，不建立全局品牌详情页。

## 品牌详情页

### 路由与页面结构

每个品牌使用稳定 slug，例如 `/brands/playaply`。页面由以下部分组成：

1. 全局导航与返回品牌矩阵入口。
2. 品牌首屏：国家、品类、品牌名和一段简短介绍。
3. 主视觉拼贴：一张主图配一至两张错位辅助图。
4. 精选系列：不等高款式图或商品图画廊。
5. 上一个品牌 / 下一个品牌导航。
6. 通用联系入口，引导品牌或买手合作。

PLAYAPLY 首版使用真实现场、装置与挂装素材。其余品牌页面使用统一的品牌化占位图，并明确保持抽象或中性，不把其他品牌的商品图冒充为当前品牌内容。

### 图片灯箱

精选系列图片可以点击打开大图灯箱。灯箱支持：

- 上一张和下一张；
- Escape 关闭；
- 关闭后焦点返回原触发图片；
- 键盘可操作的关闭与翻页按钮；
- 移动端触控按钮；
- 减少动态效果偏好下关闭非必要过渡。

## 视觉系统

### 色彩

- Canvas Warm：`#F3F0E9`，页面主背景。
- Paper：`#FAF8F3`，局部内容背景与占位画布。
- Carbon：`#171716`，标题和主要文字。
- Umber：`#725844`，来自前台木饰面与 Aano Café 器物的辅助色。
- Stone：`#9B968D`，图注和次要信息。
- Hairline：`#D8D3C9`，克制分隔线。

现有商务金 `#C8A46E` 不再作为全站默认强调色，只在确有品牌延续需要的少量位置保留。

### 字体

- 展示标题使用具有编辑感的高对比衬线字体栈，优先选择可合法加载且支持回退的 Web Font；加载失败时回退至 Georgia 系列。
- 中文正文与功能文字使用现代无衬线字体栈，优先系统字体以保证加载速度和可读性。
- 数据、图注和导航使用紧凑的无衬线样式，通过字号、字距和大小写建立层级，而非增加装饰。

### 布局签名

核心记忆点是「围绕品牌名称形成松散轨道的图片群组」。图片不画实际圆形，也不添加无意义曲线，而是通过大小、偏移和留白形成视觉重心，回应 YUAN SHOWROOM「以你为圆心、以时尚为半径」的品牌概念。

布局大胆之处只集中在图片节奏；导航、正文、按钮和状态保持安静、清晰。

## 动效与交互

- 页面进入时使用一次性的文字淡入和图片揭幕。
- 品牌卡片悬停只包含轻微缩放、图注位移和透明度变化。
- 不使用持续漂浮、无目的视差或复杂滚动劫持。
- 所有交互支持 `prefers-reduced-motion`。
- 移动端不依赖悬停；所有点击目标满足触控尺寸要求。
- 焦点样式清晰可见，品牌卡片与灯箱可完整使用键盘操作。

## 数据模型

品牌数据调整为结构化配置，每个品牌至少包含：

- `slug`
- `name`
- `country`
- `category`
- `style`
- `description`
- `coverImage`
- `galleryImages`
- `placeholder` 状态

组件只消费本地结构化数据。后续增加真实素材时仅替换图片和文案字段，不改变路由与组件结构。

未知 slug 使用统一 404。图片缺失时显示与视觉系统一致的占位状态，不输出破图。

## 素材处理

本次用户提供的照片只复制到项目公共资源目录，不修改下载目录中的原始文件。

- 两张内容相同的前台照片只保留一份网页副本。
- 项目内文件统一使用可维护的英文短文件名。
- 入选图片生成适合网页的尺寸并压缩，保留足够的高分屏清晰度。
- 清理不必要元数据。
- PLAYAPLY 相关图进入品牌详情与品牌卡片；Aano Café 图片只进入展厅/订货会体验内容。

## 组件边界

- `BrandsSection`：首页品牌拼贴、图注和品牌链接。
- `BrandCard`：单个品牌入口的图片、文本与交互状态。
- `BrandPage`：独立品牌页面布局与 metadata。
- `BrandGallery`：品牌精选图片的不等高画廊。
- `ImageLightbox`：可访问的大图浏览。
- `BrandPager`：上一个 / 下一个品牌导航。
- `EditorialMediaGrid`：服务和展厅区可复用的受控非对称图片布局。

组件只接收数据，不直接耦合百度网盘或未来后台。

## 响应式策略

- 桌面端使用受控的非对称网格与错位留白。
- 平板端减少跨栏和偏移，保持两列为主。
- 手机端使用单列或局部双列，取消可能造成横向溢出的位移。
- 图片尺寸通过 `next/image` 和明确 `sizes` 控制，避免为小屏加载不必要的大图。

## 状态与错误体验

- 占位品牌页面仍提供名称、地区、品类、简介和返回路径。
- 缺图显示品牌化中性占位，不展示无关品牌商品图。
- 灯箱遇到无效图片时跳过该项并保持关闭操作可用。
- 不存在的品牌进入 404，并提供返回首页与品牌矩阵入口。

## 验收标准

- 黑色数据墙及无用 `byTheNumbers` 数据已删除。
- 首页品牌卡片全部可点击，并进入稳定的独立品牌网址。
- PLAYAPLY 使用本次真实素材，其余品牌明确使用可替换占位内容。
- 品牌详情包含简介、视觉拼贴、精选图、品牌翻页和联系入口。
- 灯箱支持键盘、焦点恢复、移动端操作和减少动态效果。
- 首页的服务、品牌、展厅区不再重复同一种等宽卡片节奏。
- 桌面、平板和手机端无横向溢出。
- 图片经过压缩和适当尺寸处理，下载目录原文件保持不变。
- 测试、Lint、类型检查和生产构建全部通过。

## 不在本轮范围

- 内容管理后台与在线编辑。
- 百度网盘 API 或自动素材同步。
- 自动生成品牌简介或商品信息。
- 购物车、价格、库存与电商交易。
- 完整双语路由重构；本轮只保证新增结构未来可扩展双语内容。
