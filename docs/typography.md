# YUAN SHOWROOM 字体与排版标准

适用于官网新增页面及局部调整。以 `src/app/globals.css` 中的语义变量为代码来源，字体由 `src/app/layout.tsx` 加载。修改标准时同步更新本文；不要仅凭视觉印象为新页面另建字号体系。

## 字体来源

字体均来自项目已有的 Fontsource 本地依赖，不新增远程字体。

| 角色 | 变量 | 英文字体 | 中文字体 / 回退 |
| --- | --- | --- | --- |
| 导航、信息、项目名 | `--ys-font-sans` | Work Sans Variable | Noto Sans SC Variable、苹方、微软雅黑 |
| 页面标题、编辑性正文 | `--ys-font-serif` | Castoro | Noto Serif SC Variable、宋体 |
| 特定展示标题 | `--ys-font-display` | Song Myung | Noto Serif SC Variable、宋体 |

中文页面通过 `:lang(zh)` 优先使用中文字体。英文页面优先使用英文字体，遇到中文再回退。保留现有字体选择；不得用 Arial、系统粗体或新字体替换品牌表达。

固定英文内容必须显式标注 `lang="en"`，包括全站导航、品牌名、英文分类、季节编号和不翻译的活动主题。CSS 的 `:lang(en)` 会把这些内容恢复为英文页面相同的 Work Sans / Castoro / Song Myung 字体栈；不得通过给整个中文页面换字体来解决局部英文差异。Recap 的订货会主题属于固定英文内容，中英文页面统一读取数据的 `title.en`；城市、介绍和操作文字仍按语言本地化。

## 字号与文字角色

以下数值为 CSS 像素，`vw` 随视口宽度变化。截图像素、系统缩放和浏览器缩放不能直接当作 CSS 字号。

| 角色 | 变量 / 当前值 | 字体、字重与行高 |
| --- | --- | --- |
| 页面标题，如 BRANDS、COLLABORATIONS | `--ys-type-page-title`: `clamp(36px, 3.1vw, 56px)` | serif，400，`--ys-leading-title` = 1.04 |
| 大章节标题 | `--ys-type-section-title`: `clamp(28px, 2.5vw, 44px)` | 按现有页面使用 serif / display；通常 400，不用于窄侧栏项目名 |
| 精选项目名、品牌详情标题 | `--ys-type-project-title`: `clamp(24px, 2.1vw, 36px)` | 精选项目 sans、400、1.3；品牌详情沿用 sans、500、1.06 |
| 主导航 | `--ys-type-navigation`: `12px` | sans，500，1.2，字距 0；≤640px 为 11px |
| 文档标题 | `--ys-type-document-title`: `clamp(11px, 0.8vw, 13px)` | sans，500，1.35；品牌册用途 |
| 正文 | `--ys-type-body`: `clamp(13px, 0.9vw, 15px)` | 编辑性正文 serif、400，`--ys-leading-body` = 1.68 |
| 普通列表项目名 | `--ys-type-card-title`: `clamp(12px, 0.88vw, 15px)` | sans，500，1.35 |
| 分类、年份、城市等辅助信息 | `--ys-type-subtitle`: `clamp(11px, 0.78vw, 13px)` | sans，400–500，1.45–1.5 |
| 小正文、链接、图片下说明 | `--ys-type-body-small`: `clamp(10px, 0.74vw, 12px)` | sans，正文 400 / 链接 500，`--ys-leading-compact` = 1.5 |
| 图片注释、次要标签 | `--ys-type-caption`: `clamp(9px, 0.66vw, 11px)` | sans，500，1.45；不得替代正文 |

项目标题变量提取自现有品牌详情的同一字号范围。本次只让精选项目使用它，不顺带重写其他页面。`--ys-nav-size` 和 `--ys-body-size` 是仍被旧布局使用的变量，不应误认为导航链接或正文当前实际计算值；应查看具体选择器。

## 响应式

- 沿用既有 900px、640px 主断点；首页另有 1180px 规则，不扩散到内容页。
- ≤900px：页面标题变量为 `clamp(34px, 9vw, 46px)`，章节标题为 `clamp(27px, 7.5vw, 38px)`，正文为 `clamp(13px, 3.7vw, 15px)`。
- ≤640px：新板块长英文页面标题已有 `clamp(24px, 7.5vw, 46px)` 例外，避免溢出。项目名允许自然换行，不强行压缩字体、不使用 `scaleX`。
- 首页封面宣言属于已确认的独立展示例外，不作为普通内容页字号依据。

## 空间与使用规则

- 主导航保持居中，桌面项目间距为 `clamp(24px, 4vw, 64px)`；≤900px 收至 10px，≤640px 按现有两行导航使用 16px 横向间距与 44px 点击高度。语言切换独立排列。
- 精选项目标题使用项目标题档，不用章节标题档；标题下方留 20px，再排副标题、类型和年份。
- 标题大小由内容角色和可用栏宽共同决定，不要求所有 h1 或 h2 用同一个字号。正文段落不可随意升级成展示大字。
- 使用既有背景 `--ys-bg`、文字 `--ys-ink`。常规字距以 0 为基准；保留现有组件的少量例外，不靠极窄字距塞入长文。
- 留白用容器、gap、margin 和行距控制，不使用连续空格、空行或硬编码换行模拟间距。
- 修改只覆盖请求范围。引入新的语义档位前，先确认现有档位确实不适用；必须在本文说明用途。
- 小型字体、间距调整检查目标页的桌面/平板/手机表现即可，不新建样式字符串测试，不为此重复运行全套构建。

## 当前适用范围说明

官网有历史页面级字号与字重覆盖，因此本文记录的是统一角色标准及明确例外，不宣称全站所有选择器已经完成变量化。今后局部修改时对齐本文，避免未经请求的大范围重构。
