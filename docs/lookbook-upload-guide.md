# Lookbook 正式素材上传规范

适用于后续人工上传和绑定，不需要 AI 提取。以下为准备规范，不代表上传后台已经完成。

## 模特图

- 优先提供原始清晰照片，竖幅 2:3；长边建议 2400px 以上，不放大低清文件充数。
- 完整造型保留头饰、脚部和鞋履，人物上下留约 5%–8% 安全距离。半身及细节图另存，不覆盖全身原图。
- 同一季尽量统一背景、曝光、白平衡和人物占画面比例；不把真实颜色、面料纹理修掉。

## 产品白底图

- 优先正方形，建议 1600×1600px 以上，主体完整，占画面约 75%–85%；纯白背景，无文字水印及促销标识。
- 同一类别保持视角、光线和投影一致；鞋子说明单只或一双，头饰和包袋避免被裁边。
- 衣服建议正面主图，必要时另附背面、材质细节；不要把多张拼进一张主图。
- 交付清晰 JPEG / PNG / WebP，保留原始高分辨率文件，网页版本再压缩。

## 人工绑定表

每套造型记录：品牌、季节、造型编号、模特图文件名、关联产品 ID 和展示顺序。

每个产品记录：唯一 ID、品牌、类别、中英文名称、白底主图；真实款号、材质、颜色可补充，没有的数据留空。同一产品在多套造型中复用 ID，不重复上传。

示例命名结构：`品牌_季节_LOOK编号.jpg`、`品牌_款号_front.jpg`。这是命名模板，不是商品信息。

## 替换当前示意图

以真实产品摄影替换三张 AI 白底示意图，并同步核对造型绑定、中英文名称。确认真实图片上线后再移除名称里的 AI 示意标识，不把 AI 近似重建当作正式商品摄影。
