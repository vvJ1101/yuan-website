# 合作详情内容模块

当前实现为本地内容和网页渲染，不包含后台、上传服务或 CMS。后续后台输出相同结构即可接入；不得直接把未校验的外部 JSON 当作可信内容。

## 数据入口

`src/types/editorial.ts` 的 `CollaborationBlock` 定义结构，`src/data/editorial.ts` 的项目 `blocks` 数组决定阅读顺序。每个模块必须有唯一、稳定的 `id`；后台拖动排序只改变数组顺序，不改变 ID。未提供 blocks 时保留旧项目详情，空数组表示无正文模块。

| type | 内容 | 展示 |
| --- | --- | --- |
| text | heading（可选）、paragraphs | 最大 65ch 的段落 |
| image | image、caption（可选） | 横图使用内容宽度，竖图最大 720px |
| pair | 恰好两张 images、caption（可选） | 桌面双列，手机单列 |
| image-text | image、heading（可选）、paragraphs | 桌面图文并列，手机图上文下 |
| gallery | images、caption（可选） | 桌面三列，手机双列；空组不渲染 |

文字使用 `{ cn, en }`；图片使用 `{ src, alt: { cn, en }, ratio: '宽 / 高' }`。比例来自原图尺寸，不由编辑猜测；所有图片沿用 MediaFrame / Next Image，正文不接收任意 HTML。图片原比例显示，不统一裁成固定卡片。基础信息（标题、合作方、年份、简介、封面、概念、Credits）仍独立于正文模块。

## 后台接入约束

- 上传后由服务返回受控图片地址与原始宽高，并要求填写 alt；校验文件类型、大小和像素尺寸。
- 服务端校验模块类型、唯一 ID、双图数量、有效比例及中英文结构，拒绝未知模块和不允许的媒体来源。
- 不开放自定义字号、颜色、CSS 或任意脚本。沿用官网字体、1200px 容器和 900px / 640px 断点。
- 提供草稿预览与发布状态；真实内容经确认后才移除 isSample 与 noindex。上传、权限、存储及发布接口需在实际后台项目中另行实现。

## 示例

`sample-fashion` 展示所有五种模块，暂用现有官网空间及品牌海报。组图为模块演示重复使用部分素材，图注已明确说明，不表示真实合作关系。其他合作项目保留旧结构，POP-UP EVENTS 的已确认模板不变。
